# Envoy launch film script for review

## What it is

This is the proposed spoken script for a local, chat-centered film. It follows questions a resident can actually ask, then briefly shows the code behind four sponsor technologies. It is a writing and footage checkpoint, not a claim that every connected service has completed live acceptance.

## How it works

The film opens on readable, full-screen chat. A licensed 3D monitor appears only for transitions and short code inserts. Each spoken line has a matching action or result; no unrelated menu clicks or long holds. Four custom ElevenLabs voices pass the story between sections. Display the name **Envoy**; send phonetic `Onvoy` to TTS so it is pronounced **on-voy**.

`EnvoyChatFilm` preserves the 104-second first review cut. `EnvoyChatFilmMotion` uses the same eleven custom-voice recordings in a 94-second edit, including the Nearby correction that distinguishes the filtered address list from the wider map. The user approved this motion cut; it is [hosted unlisted on YouTube](https://youtu.be/7arR-ro1gS8) and embedded in Devpost.

## How to change it

Edit the spoken line and matched image together. For any requested action that fails live, change or omit that beat before voice generation. Once wording is set, update `apps/video/src/chat-narration.generated.json`, give TTS a separate phonetic `ttsText`, and regenerate only changed local clips with `node apps/video/scripts/build-chat-narration.mjs`. Raw teammate voice MP3s remain Git ignored. Set scene lengths from measured speech, then inspect the complete local audio/visual render before external sharing.

For footage, use isolated guest capture modes in `apps/video/scripts/capture-production.mjs`. Do not include the false Ottawa Service BC answer, the `[municipality name]` reply, or the failed training response. Footage from a different place must be introduced as a different place; the BC application handoff and Toronto report are separate from the Ottawa job search.

## Configuration

Target a purposeful two-to-three-minute edit, at most five minutes. Keep chat large enough to read. The model uses CreativeTrio’s CC0 monitor mesh at a roughly −20° yaw for brief depth shots; its screen plane is filled by an aspect-preserving crop of 1600×812 footage. Production is `https://envoy.surf/`. The music and TTS regeneration paths are in [video production](video-production.md).

## Dependencies

This version depends on the verified Ottawa jobs capture, corrected source-grounded Support and Nearby answers, the verified Toronto pending proposal, a redacted Envoy-only product-feedback receipt, and exact Worker/SwiftUI/Tiger/Auth0 code. Source-specific acceptance limits and asset provenance are recorded in [video production](video-production.md) and [the storyboard](video-storyboard.md).
